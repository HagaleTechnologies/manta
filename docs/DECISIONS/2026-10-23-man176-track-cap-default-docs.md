# MAN-176: superseded track-cap defaults in decision records

[MAN-166](2026-09-09-man166-confirm-hops-and-track-cap.md) remains the
current authority for the shipped `DetectorConfig::track_cap` default of 1200.
MAN-176 marks the obsolete 500 default and related capacity/Pi-budget claims
as superseded beside their historical text in these records:

- [Legacy capability matrix](2026-09-01-legacy-capability-matrix.md)
- [Decoder recall research](2026-09-09-decoder-recall-research.md)
- [M2 detector/track-pool pins](2026-07-19-m2-detector-track-pool-pins.md)

The M2 note also points to SPEC §9 and MAN-261 for the key's current location.
This documentation correction changes no default or CPU-budget policy and
preserves the historical measurements and retained pins.
