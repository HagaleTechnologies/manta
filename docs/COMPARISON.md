# manta and the other projects in its space

Visitors comparing manta with SparkSDR, sdroxide, OpenWebRX+/csdr-skimmer
or sdrainer will find claims about all of them scattered around the web.
manta deliberately makes no capability claims about the projects listed
here: this page stays neutral and links each project's own documentation,
so read about each one from its source. The scope decision (MAN-360) is
recorded in
[DECISIONS/2026-10-17-man155-related-projects-links-only.md](DECISIONS/2026-10-17-man155-related-projects-links-only.md).
What manta claims about itself is in the README's [Status](../README.md#status)
and [Non-goals](../README.md#non-goals) sections.
